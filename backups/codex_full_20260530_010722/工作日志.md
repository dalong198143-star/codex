   580|## 2026-05-29 爱马仕审计 — 备份方案
   581|
   582|### 审计结论：方案方向对，实现方式需修正
   583|
   584|### 🔴 发现的问题
   585|
   586|**P0: shutil.copytree 冷备 ChromaDB 不安全**
   587|
   588|当前 KB Server (PID 25496, 8765端口) 持续写入 chroma.sqlite3（5.7MB，最后修改 21:44）。
   589|copytree 复制过程中如果 Server 写入，备份的 SQLite 文件可能页损坏，导致备份不可用。
   590|
   591|**正确做法**：SQLite 原子备份 + 向量子目录复制。
   592|
   593|```python
   594|import sqlite3, shutil, os
   595|
   596|def _backup_chromadb(src_dir: str, backup_dir: str):
   597|    """ChromaDB 原子备份：SQLite backup API + 向量子目录复制"""
   598|    os.makedirs(backup_dir, exist_ok=True)
   599|
   600|    # 1. SQLite 原子备份（不会受并发写入影响）
   601|    src_db = os.path.join(src_dir, "chroma.sqlite3")
   602|    dst_db = os.path.join(backup_dir, "chroma.sqlite3")
   603|    conn = sqlite3.connect(src_db)
   604|    bkp = sqlite3.connect(dst_db)
   605|    conn.backup(bkp)
   606|    bkp.close()
   607|    conn.close()
   608|
   609|    # 2. 复制向量子目录（UUID 目录名，写入后不可变）
   610|    for item in os.listdir(src_dir):
   611|        src_item = os.path.join(src_dir, item)
   612|        dst_item = os.path.join(backup_dir, item)
   613|        if os.path.isdir(src_item) and item != "reports":
   614|            if not os.path.exists(dst_item):
   615|                shutil.copytree(src_item, dst_item)
   616|```
